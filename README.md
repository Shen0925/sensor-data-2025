# 七平台传感器数据：精简提交版

本版用于提交和查看“面向演化传感器网络的时空预测数据集”的首轮资料。保留本轮约定时段、粒度下已经取得的数据，以及站点、字典、来源和缺口说明；不再携带完整历史/年度原包、细间隔副本和运行辅助文件。

**这是一份目标时段提交版，保留的文件经校验与原项目对应结果一致。它不包含所有原始报告，也不意味着七个平台全量完整。完整原始采集项目另存。**

## 1. 保留了什么

| 文件夹 / 平台 | 时间范围、粒度和缺口 | 本版观测记录数 |
|---|---|---:|
| 01_USGS · USGS水文 | 2025全年日值；16,033个候选文件中15,968个有2025记录。 | 14,155,221 |
| 02_EPA · EPA空气质量与气象 | 2025全年12组日值：4组主要气体、4组颗粒物、4组气象。 | 3,082,225 |
| 03_NOAA_COOPS · NOAA CO-OPS沿海观测 | 2025年1月小时数据；19个海流请求失败、192个请求官方明确无数据，尚有缺口。 | 1,749,965 |
| 04_NOAA_GHCNh · NOAA GHCNh气象 | 2025年1月每站每UTC小时最早的一份实际报告；保留全部原始列。 | 7,570,974 |
| 05_PORTAL · PORTAL交通 | 2025年1月高速公路850,666条及车辆分类946,040条；独立行程时间、干道和公交未取得目标观测。 | 1,796,706 |
| 06_Madrid · Madrid交通 | 2025全年12个月原始15分钟交通观测及对应月度测点表。 | 157,492,750 |
| 07_Victoria · Victoria交通 | SCATS为2025可得363天，缺2月28日和12月31日；Telemetry仅10至12月92天。 | 46,892,052 |

记录含义随平台不同：USGS一条通常是站点一天某指标的一种统计；GHCNh一条报告含多项指标；SCATS一行横向放一天96个计数。因此不能将各平台行数当同一种数据量直接相加。

## 2. 怎么看

先进入平台目录读“这份数据怎么看.md”，再用索引选站点、指标或月份。USGS与GHCNh在data中保存Parquet；CO-OPS的小时产品统一在data中；PORTAL在data中保存两张CSV；EPA、Madrid、Victoria从raw的ZIP中读取原始CSV。

| 文件夹或文件 | 用途 |
|---|---|
| 各平台 `data` | 本轮目标时段的筛选或小时整理结果，只在有这类交付时建立。 |
| 各平台 `raw` | 本轮直接保留的官方ZIP；EPA、Madrid、Victoria使用。 |
| 各平台 `metadata` | 站点、位置、监测项、道路和来源目录等原资料。 |
| 各平台 `docs` | 官方字段、产品、接口及使用政策/目录说明。 |
| 各平台 `reports` | 简要数据概况、覆盖和关联缺口核查，USGS另有单站HTML预览。 |
| 根目录 `scripts` | 可运行的读取预览程序、生成本版的程序、依赖及原采集程序参考。 |
| 根目录 `reports` | 本版构建校验和原采集的跨平台缺口、关联核查等。 |
| `文件清单.csv` | 本版实际文件大小、SHA256、来源路径；其中观测文件还列行数和已知来源。 |
| `下载清单.csv` | 原始请求来源、参数、下载日期、原包校验值、失败及本版实际路径；不代表每个原包都已交付。 |
| `平台概况.csv` | 七个平台范围、保留记录数和实际观测文件数。 |

所有索引路径从本目录算起。Parquet是表格格式，可用Python/PyArrow；CSV可用Excel或Python；ZIP需读取包内CSV；JSON观测在data列表里。读取示例见scripts/使用说明.md。

## 3. 怎样精简的

USGS仅交付2025日值，不带完整历史原包；GHCNh仅交付1月小时选取结果，不带全年原包和1月all_reports副本；CO-OPS仅交付小时结果，不带6分钟海流及细间隔净空原包。PORTAL仅带两张可用小时表，不带原请求副本与去重数据库。其他三平台原ZIP保留。

站点资料、全部所选观测列、原单位、真实时间及质量字段均保留。本次复制没有进一步抽站、抽指标、降采样、插值或补零；GHCNh与CO-OPS的小时选择沿用原项目规则，属于小时内最早实际报告/观测，并非小时平均。

未复制原项目的日志、任务数据库、断点、锁、缓存、逐文件报告和空目录。本版为独立复制；原项目未删改。原采集程序参考需配合完整项目运行，查看本版数据不需要凭据。

## 4. 仍存在的缺口

CO-OPS有19个海流请求失败，192个请求官方明确无数据；PORTAL独立行程时间、干道和公交未取得目标观测；SCATS缺2025-02-28和2025-12-31；Telemetry未取得2025年1至9月。下载清单保留具体状态和原因，不能把无数据或空响应当取得观测。

部分历史站点编号无法与当前表匹配，未确认的设备身份、安装、撤除、迁移和替换状态保留为未知。不把首次观测当安装、不把缺测当退出。来源条款、字段和目录原资料在各平台docs，源URL及实际下载日期在下载清单。
